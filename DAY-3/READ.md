# Day 3 – Object-Oriented Programming & File Handling

## Project Overview

This folder contains the solutions for Day 3 of the AI/ML Internship. The tasks focus on implementing Object-Oriented Programming (OOP) concepts and Python File Handling through practical examples and a mini project.

## Contents

- Student Class
- Employee Class
- Inheritance Example
- Polymorphism Example
- Read Data from a Text File
- Write Student Records to a Text File
- Exception Handling Example
- Library Management System
- Sample Data File (`books.txt`)

## Mini Project

### Library Management System

The Library Management System is a console-based Python application developed using Object-Oriented Programming and File Handling.

### Features

- Add Book
- View All Books
- Search Book by Title
- Issue a Book
- Return a Book
- Store Book Records in a Text File
- Persistent Data Storage

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- File Handling
- VS Code
- Git & GitHub

## How to Run

1. Open the `DAY-3` folder in VS Code.
2. Run any Python file using Python 3.
3. To test the mini project, run `library_management_system.py`.
4. Ensure `books.txt` is in the same directory as the Python file.
